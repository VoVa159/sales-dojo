# Sales Dojo 🥋

A sales coach for Claude that remembers you.

Most AI sales tools give you one role-play and forget you.
Sales Dojo works inside a Claude Project, so it remembers your
real deals, your weak habits and last session's corrections,
and holds you to them next time. Every week you get a 1–10
score, so you can watch yourself improve.

Built on Sandler Selling System principles: Up-Front Contracts,
the three-level Pain Funnel, Negative Reverse, the Submarine.

## What it does
- **Drill** – rapid-fire questions, you answer out loud
- **Sparring** – it plays a tough buyer, pauses to coach you,
  and lets you retry the line
- **Call prep** – 3 points to walk in with
- **Debrief** – what went wrong, what to say next time
- **Session report + weekly score** – your progress over time
- Works in English and Hebrew (and most other languages)
- Built for voice: perfect for the morning drive

## Install

### 1. Add the skill
1. Download **`sales-dojo-skill.zip`** from this page (click it, then the download button).
2. In Claude: **Settings → Capabilities** → enable code execution →
   **Skills** → upload that zip. No unzipping needed.

### 2. Create a Project (this gives memory and progress)
1. Create a new Claude Project called "Sales Dojo".
2. Paste `project-instructions.md` into the Project instructions.
3. Upload these 4 files as Project knowledge:
   `methodology.md`, `coaching-rules.md`, `scoring.md`, `session-report.md`.
4. Make sure memory is on in Settings.
5. Open a chat in the Project and say: **"Let's start."**
   It interviews you first – no forms.
